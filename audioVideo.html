This is an audio tag

Some info about audio tag: we won't see the audio if we don't use the controls tag.
autoplay to autoplay the audio and loop to loop the audio and muted to start the audio in mute state.
Same thing is applicable for video tag

If we do not use controls in video tag, video will still appear but we won't see the controls
We can also use height and width to control the size

We can also use poster to set a poster for video
