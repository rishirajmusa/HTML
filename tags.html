There is an easy way to check whether a tag is a block or inline tag.

Block tags will always start on a new line, while inline tags will not.

We can check from inspect as well.

Just write the tag in the HTML and inspect it to see its type.

If the tag lightens up the whole line, it is a block tag.

If the tag only lightens up the text, it is an inline tag.
