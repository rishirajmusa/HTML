HTML Entities: Definition and Usage

In HTML, an entity is a special string of text used to display characters that are either reserved (like < and >) or invisible (like a non-breaking space).

What is an HTML Entity?

An entity always follows this specific structure:

  • Starts with: An ampersand (&)
  • The Name: A shorthand code (like copy or gt)
  • Ends with: A semicolon (;)

Why do we use them?

There are two main reasons for using entities:

1. Reserved Characters (The "Code Conflict" fix)

If you want to type "5 < 10" on your webpage, you cannot simply type the < symbol. The browser will think you are starting a new HTML tag (like <div>) and get confused.
Instead, you write: 5 &lt; 10
The Browser shows: 5 < 10

2. Invisible/Special Characters

Standard keyboards do not have keys for symbols like "Copyright" or a "Non-breaking space."
Instead, you write: &copy; 2026
The Browser shows: © 2026

Common Entities Cheat Sheet

Result Entity Name Description
(space) &nbsp; Non-breaking space (Forces a space that won't wrap to a new line)
< &lt; Less than (Safe way to show the bracket)
> &gt; Greater than
& &amp; Ampersand symbol
" &quot; Double quote
© &copy; Copyright symbol

Practical Example

If you want to explain code inside a paragraph without the browser trying to run it:

Instead of: <p>We use the video tag</p>
You write: <p>We use the &lt;video&gt; tag</p>
