Emmet: The Developer's Shorthand

Emmet is an essential plugin for web developers that speeds up the coding process. It works by taking abbreviations and expanding them into full HTML structures.

Common Emmet Symbols

Symbol Name Example Abbreviation Resulting HTML
> Child ul>li A list item inside a list
+ Sibling h1+p A paragraph right after a heading
* Multiplication li*3 Three list items in a row
. Class p.main <p class="main"></p>
# ID div#hero <div id="hero"></div>

The "Magic" of Grouping

You can even combine these to build entire sections in one line.
Try typing this in VS Code: div>h2+p+ul>li*2
It creates: A div containing a heading, a paragraph, and a list with two items!
